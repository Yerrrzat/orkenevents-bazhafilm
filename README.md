# ORKEN EVENTS — «Бажа»

Public site for the group screening of «Бажа» (Arman Asia Park, Astana).

Current stage: **preview** — film, halls and seat maps are shown; ticket sales are not open yet.

- `index.html` — the whole site in one file (Kazakh / Russian).
- `netlify.toml` — hosting settings for Netlify.

Hosting: Netlify, publish directory = repository root, no build command.
